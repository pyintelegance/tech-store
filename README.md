# TechStore — интернет-магазин техники

Профессиональный интернет-магазин электроники с корзиной, оформлением заказов,
расчётом доставки и админ-панелью. Работает на **Flask + PostgreSQL**.

## Возможности

**Для покупателя**
- Каталог с категориями (смартфоны, ноутбуки, планшеты, ТВ, аксессуары)
- Поиск по названию и описанию, фильтр по цене, 4 сортировки
- Карточка товара (цена, скидка, наличие, рейтинг, похожие товары)
- Корзина (добавление, изменение количества, удаление)
- Оформление заказа: имя, телефон, город, **адрес (обязательный)** и
  **дополнительный адрес (необязательно)**
- Расчёт **цены доставки** и **времени доставки (в минутах)** по городу
- Оплата при получении
- Двуязычный интерфейс **RU / UZ**

**Для администратора** (`/admin`)
- Вход по логину/паролю (защита сессий + CSRF)
- Просмотр заказов: клиент, телефон, адрес, состав, сумма
- Смена статуса заказа (новый / в обработке / доставлен / отменён)
- CRUD товаров, категорий и городов доставки

## Технологии

| Слой       | Технология                    |
|------------|-------------------------------|
| Backend    | Python 3.13, Flask 3.1        |
| База       | PostgreSQL (psycopg2)         |
| Формы      | Flask-WTF + WTForms (валидация) |
| Frontend   | HTML, CSS, JavaScript (Jinja2) |

## Установка и запуск

```bash
# 1. Склонировать и перейти в папку
git clone <repo-url> tech-store
cd tech-store

# 2. Создать виртуальное окружение
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # Linux/macOS

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Настроить окружение (.env)
#    cp .env.example .env

# 5. Создать базу данных и наполнить данными
python db.py

# 6. Запустить
python app.py
```

Сайт будет доступен по адресу: **http://127.0.0.1:5000**
Админ-панель: **http://127.0.0.1:5000/admin** (admin / admin123 — смените в .env)

## Переменные окружения

Создайте файл `.env` на основе `.env.example`:

```
DB_NAME=tech_store
DB_USER=postgres
DB_PASSWORD=postgres
DB_HOST=localhost
DB_PORT=5432
SECRET_KEY=ваш-секретный-ключ
ADMIN_USER=admin
ADMIN_PASSWORD=admin123
```

## Структура проекта

```

├── templates/        # шаблоны сайта и админки
└── static/           # CSS, JS, изображения
```

## База данных

- **categories** — категории товаров (RU/UZ, иконка)
- **products** — товары (цена, скидка, остаток, рейтинг, отзывы)
- **cities** — города доставки (цена доставки, время в минутах)
- **orders** — заказы (клиент, телефон, город, адреса, доставка, итог, статус)
- **order_items** — состав заказа
- **admins** — администраторы (хеш пароля)

## Деплой (Render)

1. Загрузите проект в GitHub.
2. На Render создайте **Web Service** и **PostgreSQL** (free tier).
3. В переменные окружения сервиса укажите `DB_*`, `SECRET_KEY`, `ADMIN_USER`, `ADMIN_PASSWORD`.
4. Команда запуска: `gunicorn app:app` (добавьте `gunicorn` в requirements.txt).
